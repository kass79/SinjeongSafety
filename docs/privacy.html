슬기로운 승무생활 개인정보처리방침

앱 이름: 슬기로운 승무생활 (com.sinjeong.safety)
시행일: 2026년 8월 21일

「슬기로운 승무생활」(이하 "앱")은 서울교통공사 신정승무사업소 승무원이 안전정보와 사내 자료를 공유하기 위해 만든 사내용 앱입니다. 앱은 아래와 같이 개인정보를 처리합니다.

1. 수집하는 항목과 목적

항목수집 방법목적
사번(8자리)이용자가 직접 입력사업소 소속 확인, 로그인 계정 식별
이름이용자가 최초 등록 시 직접 입력게시물 확인 현황·질의응답 실명 표시
PIN(6자리)이용자가 직접 설정본인 확인. 앱은 PIN 값을 저장하지 않으며 Google Firebase Authentication이 암호화하여 보관합니다.
접속 시각자동 생성계정 사용 여부 확인
게시물 확인 기록, 즐겨찾기, 조회 기록이용자 행위로 생성안전정보 전달 확인 현황 관리, 개인별 즐겨찾기 유지
질문·답변 내용 및 첨부 사진이용자가 직접 작성·첨부승무원 간 질의응답 게시
알림 토큰자동 생성새 글 알림 발송. 앱 설정에서 끌 수 있습니다.

앱은 위치정보, 연락처, 통화기록, 주소록, 사진첩 전체를 수집하지 않습니다. 사진은 이용자가 질의응답에 직접 첨부한 파일만 업로드됩니다.

2. 수집하지 않는 것

  • 앱에 내장된 사번 명단에는 이름이 포함되어 있지 않습니다. 이름은 본인이 등록할 때 직접 입력한 값만 저장합니다.
  • 광고를 게재하지 않으며, 광고 식별자를 수집하지 않습니다.
  • 개인정보를 판매하거나 마케팅 목적으로 사용하지 않습니다.

3. 처리 위탁

앱은 아래 서비스를 이용해 데이터를 보관·처리합니다. 그 외 제3자에게 개인정보를 제공하지 않습니다.

  • Google Firebase (Authentication, Cloud Firestore, Cloud Storage, Cloud Messaging, Crashlytics) — 계정 인증, 데이터 저장, 알림 발송, 오류 진단. 데이터는 Firestore 서울 리전(asia-northeast3)과 Cloud Storage에 저장됩니다.
  • 공공데이터포털(기상청) — 날씨·기상특보 조회. 개인정보는 전송하지 않습니다.

4. 보유 및 파기

  • 계정 정보와 작성 내용은 이용자가 앱을 사용하는 동안 보관합니다.
  • 퇴직·전출 등으로 사업소를 떠나거나 이용자가 삭제를 요청하면 계정과 관련 기록을 지체 없이 삭제합니다.
  • 게시물 확인 기록은 안전정보 전달 확인 목적이 끝나면 삭제합니다.

5. 이용자의 권리

이용자는 언제든지 본인의 개인정보 열람·정정·삭제·처리정지를 요청할 수 있습니다. 앱 설정 화면에서 로그아웃할 수 있으며, 계정 삭제는 아래 연락처로 요청하면 처리합니다. 새 글 알림은 설정 화면에서 직접 끌 수 있습니다.

6. 안전성 확보 조치

  • 사업소 명단에 있는 사번만 계정을 만들 수 있습니다.
  • PIN은 Google Firebase Authentication이 암호화하여 보관하며 관리자도 열람할 수 없습니다.
  • 서버 보안 규칙으로 본인 정보는 본인만, 전체 명단은 관리자만 조회할 수 있도록 제한합니다.
  • 통신은 모두 HTTPS로 암호화됩니다.

7. 아동 관련

이 앱은 서울교통공사 신정승무사업소 승무원을 위한 사내용 앱이며, 만 14세 미만 아동을 대상으로 하지 않습니다.
