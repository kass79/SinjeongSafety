슬기로운 승무생활 개인정보처리방침

앱 이름: 슬기로운 승무생활 (com.sinjeong.safety)
시행일: 2026년 9월 13일

「슬기로운 승무생활」(이하 "앱")은 서울교통공사 신정승무사업소 승무원이 안전정보와 사내 자료를 공유하기 위해 만든 사내용 앱입니다. 앱은 아래와 같이 개인정보를 처리합니다.

1. 수집하는 항목과 목적

항목수집 방법목적
사번(8자리)이용자가 직접 입력사업소 소속 확인, 로그인 계정 식별
이름이용자가 최초 등록 시 직접 입력, 또는 관리자가 사업소 직원 명부를 근거로 등록게시물 확인 현황·서명부 출력·직원 명단 관리, 댓글·질의응답에 실명 표시
PIN(6자리)이용자가 직접 설정본인 확인. 앱은 PIN 값을 저장하지 않으며 Google Firebase Authentication이 암호화하여 보관합니다.
접속 시각자동 생성계정 사용 여부 확인
게시물 확인 기록, 퀴즈 응답 결과(정답 수), 즐겨찾기, 조회 기록이용자 행위로 생성안전정보 전달 확인 현황 관리, 개인별 즐겨찾기 유지
게시물 댓글·답글, 질의응답 질문(첨부 사진 포함)·답변이용자가 직접 작성·첨부승무원 간 게시. 이름과 함께 다른 승무원에게 표시됩니다.
게시물 첨부(사진·동영상·PDF)관리자가 업로드게시물 내용 전달
알림 토큰자동 생성새 글 알림 발송. 앱 설정에서 끌 수 있습니다.
오류·비정상 종료 기록, 진단 정보Firebase Crashlytics가 자동 수집오류 원인 파악 및 수정
직원 포인트 현황 (관리자 전용)확인·퀴즈·댓글·답변 기록을 월별로 자동 집계관리자만 열람

앱은 연락처, 통화기록, 주소록, 사진첩 전체를 수집하지 않습니다. 사진·동영상·PDF는 이용자나 관리자가 앱에서 직접 첨부한 파일만 업로드됩니다. 위치 정보는 선택 기능을 켠 경우에만 사용합니다(2장 참고).

2. 위치 정보(선택 기능)

위치 정보는 설정 화면의 "현재 위치 날씨"를 켠 경우에만 사용합니다. 기본값은 꺼짐이며, 꺼두면 신정동 기준 날씨가 표시됩니다.

  • 기기에 이미 저장되어 있는 대략적 위치 정보를 기기 안에서 기상청 격자 번호로 바꾼 뒤, 격자 번호만 기상청 공공데이터 API로 전송합니다.
  • 기상특보 지역을 확인하기 위해 기기의 주소 변환 기능(안드로이드 Geocoder)으로 시·도 이름을 확인합니다.
  • 위치 정보 자체는 앱 서버(Firebase)에 저장하거나 전송하지 않습니다. 날씨 결과만 기기에 잠시 저장됩니다.

3. 수집하지 않는 것

  • 앱 설치 파일(APK)에 내장된 사번 명단에는 이름이 포함되어 있지 않습니다. 이름은 이용자가 직접 입력하거나 관리자가 사업소 직원 명부를 근거로 등록한 값입니다(1장 참고).
  • 광고를 게재하지 않으며, 광고 식별자를 수집하지 않습니다.
  • 개인정보를 판매하거나 마케팅 목적으로 사용하지 않습니다.

4. 처리 위탁 및 국외 이전

앱은 아래 서비스를 이용해 데이터를 보관·처리합니다. 그 외 제3자에게 개인정보를 제공하지 않습니다.

  • Google Firebase (Authentication, Cloud Firestore, Cloud Functions, Cloud Storage, Cloud Messaging, Crashlytics) — 계정 인증, 데이터 저장, 서버 기능 실행, 알림 발송, 오류 진단. Cloud Firestore(서울, asia-northeast3)와 Cloud Functions(서울)에 있습니다. 첨부 파일을 저장하는 Cloud Storage는 미국(us-east1)에 있습니다.
  • Anthropic(미국) — "규정에 물어보기", "3줄 요약", "OX 퀴즈 만들기", "사진 글로 정리" 기능에 쓰는 AI(Claude API)입니다. 앱 서버(Cloud Functions, 서울 리전)를 거쳐 호출합니다. 전송하는 항목은 아래 표를 참고하세요. AI 인증키는 서버에만 보관하며 앱에는 두지 않습니다. AI가 만든 결과는 화면에 초안으로 표시되고, 관리자가 저장한 경우에만 게시물에 남습니다.
  • 공공데이터포털(기상청) — 날씨·기상특보 조회. 격자 번호만 전송하며 개인정보는 보내지 않습니다.
  • 유튜브 — 게시물에 유튜브 링크가 있으면 미리보기 이미지를 유튜브(img.youtube.com)에서 불러옵니다.

아래 서비스는 국외에서 데이터를 처리합니다.

5. 보유 및 파기

  • 계정 정보와 작성 내용은 이용자가 앱을 사용하는 동안 보관합니다.
  • 퇴직·전출 시 관리자가 퇴직 처리하면 로그인이 차단됩니다. 로그인 차단은 계정 삭제가 아니며, 계정과 데이터는 삭제 요청을 받아 삭제합니다.
  • 게시물 확인 기록은 안전정보 전달 확인 현황을 관리하기 위해 앱을 운영하는 동안 보관합니다.
  • 이용자가 삭제를 요청하면 요청을 받은 날부터 10일 이내에 로그인 계정과 이름·작성한 글·댓글·확인 기록을 삭제합니다. 요청 방법과 삭제 범위는 계정 삭제 요청 페이지에 안내합니다.

6. 이용자의 권리

이용자는 언제든지 본인의 개인정보 열람·정정·삭제·처리정지를 요청할 수 있습니다. 계정 삭제는 앱의 설정 → "계정 삭제 요청" 또는 계정 삭제 요청 페이지의 안내에 따라 이메일로 요청할 수 있습니다. 새 글 알림은 설정 화면에서 직접 끌 수 있습니다.

7. 안전성 확보 조치

  • 사업소 명단에 있는 사번만 계정을 만들 수 있습니다.
  • PIN은 Google Firebase Authentication이 암호화하여 보관하며 관리자도 열람할 수 없습니다.
  • 서버 보안 규칙으로 본인 정보는 본인만, 전체 명단은 관리자만 조회할 수 있도록 제한합니다.
  • 통신은 모두 HTTPS로 암호화됩니다.
