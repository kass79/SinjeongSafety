삭제 요청 방법

삭제되는 정보

  • 로그인 계정(사번으로 만든 계정과 PIN 인증 정보)

  • 작성한 댓글·답글
  • 질의응답 질문(첨부 사진 포함)과 답변
  • 관리자가 직원 명부를 근거로 앱에 등록한 이름
  • 직원 포인트 집계(위 기록으로 계산되므로 함께 사라집니다)

삭제 후에도 남는 정보
